# AI Document Reviewer - Frontend

React TypeScript frontend for the AI Document Reviewer application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```env
REACT_APP_API_URL=http://localhost:8000
```

3. Start development server:
```bash
npm start
```

## Build for Production

```bash
npm run build
```

The build folder will contain the production-ready files for deployment to GitHub Pages.
