Stock Analysis Portfolio

Data Visualization & Market Analysis Project

About This Project

A comprehensive stock market analysis tool that collects real-time stock data, stores it in a SQLite database, and generates beautiful visualizations. This project demonstrates data collection, database management, and data visualization skills using Python, yFinance, pandas, and matplotlib.

Real-Time Data

Fetches live stock data from yFinance API for major tech stocks

SQL Database

Stores historical price data in SQLite for analysis and queries

Visualizations

Generates 6 different types of charts and analysis graphs

Automated Pipeline

Complete automation from data collection to visualization generation

Visualizations

Price Trends

Individual stock price charts showing closing prices over time with high-low ranges. Perfect for tracking long-term price movements and volatility patterns.

Volume Analysis

Trading volume bars for each stock, helping identify periods of high activity and potential market interest or significant events.

Price Comparison

Normalized price comparison where all stocks start at 100, making it easy to compare relative performance across different stocks regardless of their absolute prices.

Daily Changes

Daily percentage changes visualization with color coding (green for gains, red for losses). Shows day-to-day volatility and momentum.

Price Range

High-low price ranges with close price lines, illustrating the trading range and closing position within each day's price action.

Summary Statistics

Four-panel summary dashboard displaying current prices, price ranges, trading volumes, and key statistics for quick market overview.
